Projects

Three things I have built or practised on.

Ant Mosaic

Puzzle game for the browser

A puzzle game where ants pick up blocks of the same colour until none are left. It has four modes: Level Up, Endless, Pop (a 60-second race) and Versus, plus daily challenges, a shop and a leaderboard.

Play the game

Alertify

Crypto analytics web app

A tool that monitors crypto prices from different oracles (RedStone, Chainlink and Pyth) and lets you compare them side by side. The dashboard shows how many feeds each oracle provides and lists live prices.

Open Alertify

Number Guessing Game

Python command-line program

A beginner Python program. The computer picks a number from 1 to 100 and says "too high" or "too low" after each guess until you get it right. It counts your tries and lets you play again.
